# LegalEase - AI Legal Document Generator

An AI-powered platform that generates professional legal documents and explains them in Tanglish for common people.

## 🚀 Features
- Generates Lease Agreement, NDA, Employment Contract
- Exports to PDF & DOCX
- Bilingual Explanation (English + Tanglish) for Accessibility
- Built with Gemini 1.5 Pro, FastAPI, Streamlit

## ⚙️ Setup
1. Clone repo
2. Add GEMINI_API_KEY in .env file
3. pip install -r requirements.txt
4. uvicorn main:app --reload

## 🎯 Innovation
Solving complex legal language problem by providing Tanglish explanations, making legal documents accessible to Tamil Nadu people.
